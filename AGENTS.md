# Training rules

Read TRAINING_PARAMETERS.md before changing training, rewards, targets, or phase settings.
Only the current 9-observation / 3-torque native PX4 control interface is supported by the public entry point.
Do not start training unless explicitly requested. Verify running processes and logs instead of inferring status from this document.
Keep generated assets, checkpoints, logs and local runtime paths outside Git.
Update the parameter document whenever the user approves a configuration change.
