## 根因证据

1. 可行见证是当前合法actor对应的零增量：九个成本半空间均取0，bias盒上下界均包含0，且当前actor通过原KL/ESS/cost/weight/action/frozen全部非线性守卫。pre40的pitch负向可表示余量9.64064384e-9。不存在额外未检查的提案投影：旧提案构造只有九个成本半空间；v1加入两组bias交集；其它约束是原scheduler接受守卫。零增量只证明可行，不能作为有效更新通过。
2. pre40原始成本梯度范数0.00615029–0.18314898，原Dykstra已逐行单位化。cost2/cost3法向余弦0.998598；全部13法向rank11，两个零奇异值来自bias上下界相反法向，不能把形式上的1.23e20全谱条件数解释为不可行。去掉零奇异值的条件数7138.67，说明几何相关性较强。原预声明常数没有变化。
3. 512轮后的正残差2.27895246e-10出现在cost3（pitch cruise），原始梯度点积3.69900192e-11；bias盒残差0。末轮变化1.65307098e-10。二者分别超过预声明1e-12标准约227.90/165.31倍，故拒绝正确。末64轮残差收缩比中位数0.99317493，是缓慢收敛而非NaN/发散；没有靠延长512轮或放宽标准令其通过。
4. 独立NumPy重写递推与原torch最终增量差1.69407e-20；Dykstra校正不变量残差1.86347e-20。证据排除本次递推的明显实现错误，但不声称所有输入上无bug。新SVD解在同一边界下取得约1e-18原始可行残差，说明旧1e-12标准并非此点的float64精度极限；不需要放宽容差。

## 最小修复及固定对照
