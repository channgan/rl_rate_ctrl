## 下一版完整关键约束（准备完成，未执行）

1. **从 A 重新开始**，不是从 V47 final40 接着训。A 模型 ID 2428576135，binary SHA256 `0bdfed33c8a2ab7ae5901d522f8c493184924c633c25e4ad129d5da4f8c24f1e`；新 Adam 无历史 moments。仅 154 个 RP 输出头参数更新；主干/yaw/gate 冻结，独立网络不引入 PID 教师或位置/姿态真值。

2. 学习率固定 **3e-5**，不扫描、不自适应。为保留 V47 的目标时序，更新 1–10 仍 alpha=1 且原平滑梯度≤10% 检查硬停；11 起应用原只降不升的全局平滑 alpha（目标 0.099、复测≤0.1，非有限硬停）；不是从 V47 末值 0.2820 开始。首次及第二批 memory/速度覆盖原硬门槛保留；21 起历史 memory 分位仅诊断，必须由本次 batch0 真实覆盖报告证明初始通过，不沿用旧通过标记。4000/s、其余奖励、首段权重和物理终止条件不变。

3. **4 批×7 条新采集×10 次更新 = 28 条新采集、40 次更新**。每批仅使用本批当前行为 actor 采集的七条，继承新运行前一批的 Adam moments，不混入旧行为数据。每次 2000 条加权 minibatch，AR 探索 std0.001 和20 ms时常保持。入口校验新根目录、job、batch、seed、case、actor ID、已审计状态并拒绝旧/重复数据。

4. 训练 native 硬上限 **2,000,000**，28 条各预留47,000合计 **1,316,000**；剩余预算不授权额外采集/探测/自动重试。进入/评分/失败均计费；未知失败按预留保守计费。任何物理、存活不足2048、同步>4ms、有限值、数据或优化守卫失败立即停止保留证据。沿用本地每条1800s超时触发停止；总耗时不能从离线单步推断。

5. 候选预先固定为第 **40 次正式更新**，不据开发分数选择中间 checkpoint。每批 checkpoint 仅作审计/恢复证据。达到40后停止训练、冻结 actor/hash，再完整开发验收；不能仅因成功启动或存活而宣布完成。

6. 验收 **九工况×新种子480301/480302×PID/A/final40 = 54 项**，独立硬预算 **3,000,000**，36 NN×47,000 +18 PID×56,000=**2,700,000**预留，无自动重试/额外筛选。完整矩阵前不决策，原逐轴RMSE/P99、电机、低速全段/巡航/覆盖、保护工况及重复范围规则不变；原100 Hz与实际消费参考native两种口径并列，首3秒不删。holdout12701/12702封存，上游PX4/PID、plant、传感器、控制分配及合格native二进制不变。

7. 这是一版受限假设检验。离线通过不等于闭环通过；若学习量扩大仍未过全矩阵，保留 A，不放宽门槛，另立下一假说。新开发种子无法消除所有闭环初始状态差异，不能把与V47历史分数差简单归为LR的因果效应。
